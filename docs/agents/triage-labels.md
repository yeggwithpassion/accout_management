# Triage 标签

技能使用五个标准 triage 角色，本文件将其映射到本项目实际使用的标签。

| 技能中的角色 | 本仓库标签 | 含义 |
|-------------|-----------|------|
| `needs-triage` | `待评估` | 需要维护者评估此 issue |
| `needs-info` | `待补充` | 等待提交人补充信息 |
| `ready-for-agent` | `AI可接` | 规格完整，AI 智能体可独立接取 |
| `ready-for-human` | `需人工` | 需要人工实现 |
| `wontfix` | `不予处理` | 不予处理 |

当技能提到某个角色（如"打上 AI 可接标签"），使用本表第三列对应的标签字符串。

在 Issue 文件中，状态以 `Status: <标签>` 形式记录在文件顶部附近。
