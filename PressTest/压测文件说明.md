# 压测文件说明

本文件列出本次压力测试涉及的主要文件及用途。

## PressTest 目录

- `PressTest/run-pressure-tests.ps1`
  - 压测入口脚本。
  - 负责选择 H2 / MySQL 模式并调用 `PressureTestSuite`。

- `PressTest/scenario-config.json`
  - 压测场景定义文件。
  - 记录场景名称、目标接口、并发度、总任务数、样例类型和通过标准。

- `PressTest/samples/create-security-account.json`
  - 证券账户开户样例。

- `PressTest/samples/create-fund-account.json`
  - 资金账户开户样例。

- `PressTest/samples/update-fund-balance-idempotent.json`
  - 资金回调幂等样例。

- `PressTest/samples/update-security-holding-idempotent.json`
  - 持仓回调幂等样例。

- `PressTest/pressure-test-report.md`
  - 压测报告。
  - 汇总技术栈、方法、样例、结果、失败原因分析和结论。

- `PressTest/results/pressure-test-results.json`
  - 结构化结果明细。

- `PressTest/results/pressure-test-summary.csv`
  - 压测汇总表。

## 测试代码

- `src/test/java/account/perf/PressureTestSuite.java`
  - 压测执行主类。
  - 负责初始化测试环境、执行场景、统计结果、回查数据库并生成报告。

## 辅助文件

- `.gitignore`
  - 忽略模板 PDF 和本地代理说明文件。

- `AGENT.md`
  - 记录仓库级长期要求，包括 `PressTest/` 目录约束和报告要求。
